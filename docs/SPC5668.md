# SPC5668G / MPC5668G implementation evidence

Version 0.9.0 adds `spc5668g`; CLI aliases `spc5668`, `mpc5668` and `mpc5668g`
select it. This is the NXP/Freescale MPC5668G family, including SPC-prefixed
orderable parts, not an inferred ST SPC56 sibling. See the official
[product page](https://www.nxp.com/products/MPC5668G) and
[data sheet](https://www.nxp.com/docs/en/data-sheet/MPC5668x.pdf).

## Documented map and behavior

The reference is MPC5668xRM Rev. 4, January 2011: chapters 8 (BAM/security),
11 (Flash) and 34 (JTAG). These establish the implementation's physical map
and debug selection; the supplied P&E algorithms were used for comparison.

| Item | Implemented value |
| --- | --- |
| CFLASH | `00000000–001FFFFF`, 2 MiB |
| Blocks | Eight 16 KiB, two 64 KiB, two 128 KiB, six 256 KiB |
| SHADOW | `00FFC000–00FFFFFF`, 16 KiB |
| C90FL controller | `FFFF8000` |
| Core selection | 5-bit IR; e200z6 `11`, e200z0 `19`; OnCE `10` |
| IDCODE | Part `0826801D`, revision nibble masked; an explicit expected ID stays exact |
| Page programming | 16-byte aligned page, or one 8-byte ECC unit; no block/page crossing |
| SHADOW censorship word | `00FFFDE0`, high halfword CW must remain `55AA` |
| Serial-boot password | 64 bits at `00FFFDD8`; no JTAG password operation |

Table 11-1 defines Flash geometry; section 11.4.1.3 specifies four words per
programming page. Chapter 34's instruction table defines the core selectors.
Table 8-2 and the Flash map place the single censorship word; `00FFFDE4` is
general data, not the duplicate word used by SPC560B. SHADOW erase retains the
configuration tail from offset `3DD0`, and rebuilds it before honoring Stop.

Memory uses physical Nexus access with both cores halted (a secondary held in
reset is also quiescent). Session preparation disables the watchdog and Flash
read buffering. Wrong-part IDCODE is rejected before core reset/Flash writes.
Uncensored targets only; no separate DFLASH or OTP region is exposed.

## Static comparison and inference limits

Inspected locally: P&E `NXP_MPC5668_1x32x512k_cflash.pcp` version 1.06 and
`NXP_MPC5668_1x32x4k_Shadow_Blk_NXP_C90FL_Driver_100.pcp` version 1.04,
both dated 2017-07-11. Headers agree on geometry/controller and watchdog setup.
REA objdump evidence:
`ev_319f569b664e5f7b290da4d9c8bf996b1baac4fac7056dbc70d603d7f1314f5b`.
Decoded CFLASH artifact SHA-256:
`06161b26beee1ed3027b64a123deeecb2a1570eb4428155b8eb190b4ad17cebe`.

Observed loader code follows PGM, data loading, EHV and DONE/PEG checks.
Its `30000000` / `30FFC000` effective aliases are not physical Nexus addresses.
A 64-byte loader descriptor does not override the manual's 16-byte page limit.
The implementation therefore uses the documented 16-byte page with 8-byte
fallback. Static disassembly does not demonstrate actual P&E execution or speed.
No P&E RAM loader, executable or PCP file is embedded or distributed.

## Checks and open work

An independent bit-clocked JTAG/Nexus fixture exercises both-core selection,
reset ordering, IDCODE revision matching, physical addressing, preparation,
page programming, read-back and bus failures. Controller tests cover grouped
erase, locks, SHADOW preservation, censorship rejection and safe Stop.

No physical SPC5668G was connected for this work. Read/erase/write timing,
electrical wiring and behavior across silicon revisions remain unqualified.
This is not full PROGPPCNEXUS feature or performance parity.

The Wiring tab shows signals rather than assuming a 10- or 14-pin board header.
Connect TDI/TDO/TCK/TMS, ground and target voltage reference according to the
board schematic. The selected reset lead goes to RESET; the other drives JCOMP
high. Connector pin numbers must come from the actual board.
